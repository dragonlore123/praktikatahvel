# PraktikaTahvel

Veebirakendus, kus TTK tarkvaraarenduse õpilased leiavad praktikakohti ja jagavad oma praktikakogemusi.

## Mida ja kellele

Praktikakohta otsides on info laiali: kursusekaaslaste vestlustes, vanades meilides ja kuulujuttudes. Keegi ei tea täpselt, millised firmad praktikante võtavad, milliste tehnoloogiatega seal töötatakse ja kuidas eelmistel praktikantidel läks.

PraktikaTahvel koondab selle info ühte kohta:

- **ettevõtete nimekiri** koos linna, tehnoloogiate ja keskmise hindega
- **otsing ja filtrid** tehnoloogia ja linna järgi
- **õpilaste arvustused** praktikakohtade kohta (hinne 1–5 ja kirjeldus)
- **konto**, et lisada uusi ettevõtteid ja arvustusi
- **administraator**, kes saab eemaldada sobimatut sisu

**Sihtrühm:** TTK tarkvaraarenduse õpilased, kes otsivad praktikakohta või on praktika juba läbinud.

## Tehnoloogiad

Node.js, Express, MySQL, HTML/CSS/JavaScript
